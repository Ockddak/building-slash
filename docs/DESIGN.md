# 빌딩 베기 — 손맛 기준 문서

이 문서는 "바꾸면 게임의 느낌이 달라지는 값"과 그 값을 정한 이유를 적어 둔 곳이에요.
값을 바꾸고 싶을 때는 먼저 이 문서를 보고, 바꿨다면 이유와 날짜를 아래 결정 기록에 남겨 주세요.

## 이 게임의 핵심 (바꾸면 안 되는 것)

- **행위**: 떨어지는 건물을 아래에서 점프해서 한 층씩 벤다. 막기는 깔리기 직전의 마지막 수단이다.
- **촉감**: 베면 건물이 살짝 위로 튕긴다. 층이 부서지면 남은 점프 힘으로 위층까지 이어서 벨 수 있다(관통).
- **주제**: 층마다 스트레스 문구가 적혀 있고, 그걸 베어 버리는 해소감이 핵심이다.
- **한 판 길이**: 보통 실력 기준 약 1분. 처음 하는 사람도 첫 보스(5번째 건물)를 볼 기회가 있어야 한다.

## 손맛 값 (src: `index.html` 게임 규칙 부분)

| 값 | 지금 | 의미 | 정한 이유 |
|---|---|---|---|
| 점프 힘 `vp` | 720 | 점프 높이 약 136 | 건물 3층 정도 아래까지 닿는 높이 |
| 칼 닿는 거리 `REACH` | 36 | 머리 위로 칼이 닿는 거리 | 한 층(42)보다 조금 짧게, 타이밍이 필요하도록 |
| 벨 때 건물이 튕기는 힘 | 110 + 콤보×5 (최대 +90) | 연타할수록 버티기 쉬워짐 | 연타 보상 |
| 관통 감소율 | 층마다 남은 힘 ×0.75 | 보통 2~4층에서 멈춤 | 무한 관통 방지 (사용자 테스트 의견) |
| 땅에서 막기 튕김 | 200 + 건물 번호×6 | 막은 뒤 바로 다시 대응해야 함 | 처음 값(430)은 너무 세다는 의견으로 절반으로 |
| 공중 막기 튕김 | 170 + 건물 번호×5 | 땅보다 약함 | 발판이 없는 느낌 |
| 막기 유지 / 재사용 대기 | 0.38초 / 1.1초 | 막기 남발 방지 | |
| 건물 사이 쉬는 시간 | 3초 | 다음 건물 미리 보기 | 사용자 테스트 의견 |
| 목숨 `LIVES` | 3 | 깔리면 하나 감소, 1.2초 무적 | 아래 봇 측정 참고 |
| 후반 가속 `LATE_G` | 35 | 8번째 건물부터 건물마다 낙하 가속 +35 | 고수가 너무 오래 버티지 않게 |
| 보스 | 5번째 건물마다, 3층 × 5번 | | 중간 목표 |
