빌딩 베기 개인정보처리방침

시행일: 2026년 10월 24일 · 문의: [여기에 이메일 주소를 넣으세요]

1. 수집하는 개인정보

빌딩 베기(이하 "게임")는 이용자의 개인정보를 수집하거나 운영자의 서버로 전송하지 않습니다. 회원가입이나 로그인이 없습니다.

2. 이용자 기기에만 저장되는 정보

게임을 편하게 이용하도록 다음 정보를 이용자 기기의 브라우저 저장소(localStorage)에만 저장합니다. 이 정보는 운영자가 볼 수 없습니다.

  • 최고 점수
  • 이용자가 직접 선택한 얼굴 사진(캐릭터 꾸미기용, 잘라 낸 작은 이미지)
  • 이용자가 직접 적은 스트레스 문구
  • 세대 선택, 소리 켜기/끄기, 튜토리얼 완료 여부

3. 사진 접근

얼굴 사진은 이용자가 직접 고른 경우에만 사용하며, 기기 밖으로 전송하지 않습니다. 결과 이미지 공유는 이용자가 직접 선택한 공유 기능으로만 이루어집니다.

4. 정보 삭제

게임 화면의 '게임 정보 · 개인정보 안내'에서 '이 기기에 저장된 게임 데이터 모두 지우기'를 누르거나, 브라우저의 사이트 데이터를 삭제하면 모든 정보가 지워집니다.

5. 외부 서비스

게임을 올린 호스팅 업체가 서버 운영을 위해 일반적인 접속 기록(IP 주소 등)을 남길 수 있습니다. 게임 자체는 외부 분석 도구나 광고를 쓰지 않습니다.

6. 아동의 이용

게임은 개인정보를 수집하지 않으므로 별도의 아동 개인정보 처리 절차가 없습니다.
